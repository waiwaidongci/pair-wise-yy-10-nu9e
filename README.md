# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

已实现闭环：
- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付。
- 今日待阴干、缺陷作品、最近交付三类列表。
- 可更新状态、记录断线/翘线、查看作品详情。
- 支持筛选、交付排序、localStorage 持久化和 JSON 导出。

## 预订锁单台

防止口头预订重复接单。三个业务关注点分别放在独立文件：

- `js/booking-rules.js`：锁单规则（纯逻辑，不依赖页面与存储，可单独测试）。
- `js/booking-ledger.js`：预订台账（独立 localStorage 键 `zfl42Bookings`，不改动旧作品数据）。
- `js/booking-ui.js`：锁单台页面操作（候选作品卡片、锁单表单、台账、看板锁单角标）。

锁单规则：

1. 只有「待交付 + 贴线进度 100% + 无缺陷」的作品可以锁单；录入客户、定金、定金截止时刻（可备注）。
2. 锁单有效期分「待收定金」「已收定金」两态，期间同一作品不能再接第二单；冲突会提示原客户。
3. 到截止时刻仍未收到定金，锁单自动释放，作品可重新接单（每次打开/操作及每 20 秒巡检一次）。
4. 收到定金后改稿或补记缺陷：订单失效、作品回到待交付；尚未收到定金期间改稿或补记缺陷：直接释放锁单。
5. 台账保留全部历史（待收定金、已收定金、已释放、已失效）及操作经过；锁单与释放/失效均会写入作品流转记录。

原有筛选、JSON 导出和 `zfl42Works` 旧数据结构均保持不变。
