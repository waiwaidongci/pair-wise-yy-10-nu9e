# zfl-42 小型漆线雕工坊管理

独立静态前端应用，直接打开 `index.html` 即可使用。

已实现闭环：
- 新增作品并记录胎体、纹样、线条、贴线进度、阴干日期、金粉状态、缺陷和交付日期。
- 工序看板覆盖贴线中、待阴干、上金粉、待交付。
- 今日待阴干、缺陷作品、最近交付三类列表。
- 可更新状态、记录断线/翘线、查看作品详情。
- 支持筛选、交付排序、localStorage 持久化和 JSON 导出。

## 预订锁单台

口头订下作品后在此登记，避免负责人重复答应：

- **可锁单条件**：作品状态为「待交付」、贴线进度 100%、且没有缺陷，三条同时满足才出现「锁单」。
- **锁单登记**：记录客户姓名、定金金额、定金截止时刻；生成「待定金」锁单。
- **不能重单**：锁单有效期内（待定金未到期，或已确认收到定金）再接第二单会被拒绝，并提示原客户姓名、定金与截止时刻。
- **到期释放**：到截止时刻仍未收到定金，台账自动转为「已释放」，作品回到可接单状态（页面每 15 秒检查一次）。
- **收到定金**：「待定金」转为「已锁定」。
- **改稿 / 补记缺陷**：已收定金（或待定金）的锁单因此失效，状态转为「已失效」，作品回到待交付；补记缺陷的作品因带缺陷不再可锁单。
- 锁单有效期内直接改作品状态会被拦截，需先「改稿失效」。

业务文件按职责拆分，原有筛选、JSON 导出与作品数据（`zfl42Works`）均保留不变：

| 文件 | 职责 |
| --- | --- |
| `lock-rules.js` | 锁单规则（纯逻辑）：可锁单判定、建锁、冲突提示、到期释放、收款、失效 |
| `booking-ledger.js` | 预订台账：独立 localStorage key `zfl42Bookings` 的存取、到期同步与状态流转 |
| `booking-page.js` | 页面操作：锁单台三栏台账、锁单弹窗、看板锁单槽位、与改状态/记缺陷/详情的联动 |
